# Dashboards Corporativos - Grafana

Este repositório contém dashboards criados no **Grafana** com foco em monitoramento, controle e análise de dados em tempo real. As soluções foram desenvolvidas para oferecer **visões operacionais, gerenciais e estratégicas**, atendendo a diferentes áreas da organização.

---

## 📊 Visões Disponíveis

### 1. **Gestão de Contratos**
![Assinatura de contratos Grafana](https://github.com/user-attachments/assets/d55b298d-91b5-4565-8a70-29267892298b)


- Controle de contratos assinados e pendentes
- Painel com **tempo para vencimento** (5 anos e 3 meses)
- Classificação de risco por cor:
  - 🔴 Vencidos
  - 🟡 Próximos do vencimento
  - 🟢 Em dia
- Total de contratos ativos
- Visão clara para **gestão de riscos contratuais**

---

### 2. **Acompanhamento da Atualização de Computadores**
![acompanhamento de atualização grafana](https://github.com/user-attachments/assets/9af47c5e-59e1-49f2-9d4d-82224a9797b9)


- Status da atualização para **Windows 11** em **computadores e notebooks**
- Quantidade de dispositivos com:
  - ✅ Atualização concluída
  - ⚠️ Em atualização
  - ❌ Fora dos requisitos mínimos
- Lista detalhada dos equipamentos que necessitam troca
- Indicador de atingimento de metas por tipo de dispositivo

---

### 3. **Inventário de Equipamentos de TI**
![invantario TI Grafana](https://github.com/user-attachments/assets/bc16c436-69f0-4e74-bb9c-1c282eb11d31)


- Equipamentos por localidade (lojas e matriz)
- Distribuição por sistema operacional: Windows 10, Windows 11, Linux etc.
- Quantitativo total por tipo de equipamento:
  - Computadores, notebooks, monitores, nobreaks, celulares, scanners, entre outros
- Integração com base de dados para status atualizado em tempo real

---

## 🧠 Potencial do Grafana

Além dos dashboards atuais, o **Grafana permite a criação de visões personalizadas** para diversas áreas:

| Área                 | Aplicações Possíveis                                                                 |
|----------------------|--------------------------------------------------------------------------------------|
| **TI / Infraestrutura** | Monitoramento de redes, contratos, dispositivos, SLA, disponibilidade de serviços |
| **Projetos**           | Indicadores de avanço, cronogramas, status por fase, burndown charts              |
| **Financeiro**         | Relatórios de contas a pagar/receber, fluxo de caixa, comparativos orçamentários  |
| **Gestão**             | Metas e KPIs, controle de despesas, produtividade de equipes                      |
| **Operacional**        | Dashboards em tempo real para tomada de decisão imediata                          |
